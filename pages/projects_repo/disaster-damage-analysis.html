Disaster Damage Analysis

A machine learning pipeline that ingests pre- and post-disaster satellite imagery and automatically classifies damage severity across affected regions — enabling faster, data-driven triage for emergency response teams.

GitHub
overview

When disasters strike, rapid damage assessment is critical for directing aid. This project builds a change-detection pipeline on top of the xBD dataset — a large-scale collection of before/after satellite image pairs spanning hurricanes, floods, wildfires, and earthquakes.

The model takes a co-registered pre- and post-event image pair, extracts difference features via a Siamese encoder, and classifies each building polygon into one of four damage levels: no damage, minor, major, and destroyed. Output overlays are exportable as GeoJSON for use in GIS tools used by disaster response organisations.

key features
  • Siamese ResNet-50 backbone with a shared encoder for pre/post image feature extraction
  • Change-attention module that highlights regions of significant visual shift between image pairs
  • Four-class damage severity head trained on xBD with class-balanced sampling to handle label imbalance
  • Building polygon masking using OpenStreetMap footprints to focus predictions on structures
  • GeoJSON export with damage scores and confidence values per building polygon
  • Tile-based inference pipeline for processing full satellite scenes without memory overflow
