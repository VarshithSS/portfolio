Browser Agent

An autonomous LLM-powered agent that navigates, clicks, and fills forms on the web without human input — given only a plain-English goal.

GitHub
overview

Browser Agent is a fully autonomous web navigation system built on top of a vision-language model. Given a natural language task like "Book a flight from Delhi to Mumbai next Friday under ₹5000", the agent perceives the current browser state, reasons about the next action, and executes it — repeating until the goal is complete or it determines the task is impossible.

The agent uses a ReAct-style loop: observe → think → act. Each step, it receives a screenshot (or DOM snapshot) as context, generates a structured action (click, type, scroll, navigate), and dispatches it to a headless Playwright browser.

key features
  • Vision + DOM fusion — combines screenshot embeddings with parsed DOM for reliable element targeting
  • Multi-step planning with backtracking when the agent detects it has gone off-course
  • Rate-limit aware retry logic with exponential backoff on LLM API calls
  • Structured action schema enforced via constrained decoding — no free-form hallucination of selectors
  • Session persistence across tabs and page reloads using cookie + localStorage snapshots
  • Evaluation harness with 40+ benchmark tasks spanning e-commerce, forms, and search
