Work in Progress VLM / LLM Robotics C-Learning
Ambiguity Minimization in VLMs
using Contrastive Classification
Singampalli Sri Varshith  ·  June 2026  ·  Research Proposal
In cross-lingual robotic control, VLMs processing vernacular instructions (e.g., Hindi) frequently encounter underspecified intents — such as "mug uthao" when two mugs are present. Standard supervised fine-tuning forces the model to guess, producing catastrophic physical failures. We frame this as a probabilistic goal-reaching problem inspired by C-Learning, partitioning the interaction space into Ambiguous and Unambiguous states. A two-stage framework first trains a binary classifier over VLM embeddings to model the density of unambiguous actions, then extracts a policy using classifier-guided AWR that learns to ask clarification questions before committing to execution.
Problem Formulation
POMDP Tuple  M = (S, A, P, O)
S
True hidden user intent — the latent task index k* ∈ {1,…,K}
O
Robot's context: visual scene + dialogue history up to turn t
A
Either a_ask (clarification query) or COMMIT(k) (terminal retrieval)
P
Transition driven by user responses; good questions reduce task uncertainty
Multi-Turn Task Retrieval

Instead of generating a free-form plan, the agent maps ambiguous dialogue to one canonical task from a fixed library T = {t₁, …, t_K}.

e.g. t₈ = pick up the ketchup and place it in the basket
e.g. t₉ = pick up the salad dressing and place it in the basket

The key shift: ambiguous instruction → clarification dialogue → retrieve t_k*

Two-Stage Method
Training Tuple τ

o_ambig

"Do you mean the red one or the dressing bottle?"  y=1 (positive)

"The dressing bottle."

Phase 1 — Ambiguity Classifier C_θ
Frozen VLM extracts embeddings [o_emb ; a_emb]. A lightweight 3-layer MLP predicts whether the action is ambiguity-resolving. Trained on BCE over positive and negative pairs.
Architecture
e = VLMfrozen(o, a)
C_θ(o, a) = σ(MLPθ(e))
Loss
L = −𝔼[ log C_θ(o_unambig, a_plan)
+ log C_θ(o_ambig, a_ask)
+ log(1 − C_θ(o_ambig, a_guess))]
Phase 2 — Policy π_φ via AWR
Qwen2-VL-2B fine-tuned with LoRA. Frozen C_θ weights ambiguity-resolving trajectories via Advantage-Weighted Regression. Low C_θ ≈ 0 suppresses guessing; high C_θ ≈ 1 amplifies <question> and <output> tokens.
Policy Loss (AWR)
w(o,a) = exp(C_θ(o,a) / β)

L_policy = −𝔼[ w(o₁,a₁) log π_φ(a₁|o₁)
+ w(o₂,a₂) log π_φ(a₂|o₂)
+ w(o₃,a₃) log π_φ(a₃|o₃)]
Three I/O pairs
o₁=ambig → a₁=<question>
o₂=ambig → a₂=<wrong output>
o₃=resolved → a₃=<output>

End-to-End Inference Loop
1
Input observation = [Image + Scene Description + Query] fed to the fine-tuned VLM
2
VLM autoregressively generates response wrapped in XML tags: <question> or <output>
3
If <question> → ask human, append reply to observation history, loop back to step 1
4
If <output> → extract canonical task string, forward to frozen downstream VLA (e.g., OpenVLA, Pi0.5) for motor execution
Cross-Lingual Ambiguity Taxonomy
Lexical / Action Polysemy
"Butter laga do" — laga do means attach / place / apply. Could be place(butter, table) or smear(butter, bread). VLM must output <question>.
Pro-Drop (Implicit Args)
"Nikaal lo" — Hindi grammatically permits dropping the object. "Take [it] out" lacks the target argument required by the English VLA.
Spatial Frame-of-Reference
"Uss ke aage rakho" — "Put it in front of that" can mean intrinsic (touching the object) or relative (between object and user). Spatial frame is underspecified.
Safety / Irreversibility
"Hata do" — can mean move or throw away. If directed at an important document, guessing wrong leads to irreversible destruction. Mandatory clarification.
